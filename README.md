# Osteopat Danilov

Personal website of osteopathic physician Dmitry Danilov.

## Status

The production one-page website is implemented. The temporary Hero portrait
must be replaced with the final approved portrait before public launch.

## Stack

- React
- TypeScript
- Vite
- Native CSS with custom properties and CSS Modules
- ESLint and Prettier

## Local development

Requires a current Node.js LTS release and npm.

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the Vite development server
- `npm run build` — type-check and create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint with zero warnings allowed
- `npm run typecheck` — run TypeScript project checks
- `npm run format` — format project files with Prettier
- `npm run format:check` — verify formatting without changing files
