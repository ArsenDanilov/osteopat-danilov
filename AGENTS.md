# Project conventions

## Project

Personal website of osteopathic physician Dmitry Danilov.

## Stack

React + TypeScript + Vite.

## Design

Quiet medical confidence without sterility. Use a warm editorial medical aesthetic with Lora and Manrope, warm ivory, graphite, and muted forest green.

## Engineering

- Keep architecture simple and avoid overengineering.
- Do not use a UI framework or Tailwind.
- Use CSS custom properties and CSS Modules.
- Check current library documentation through Context7 when relevant.
- Prefer stable APIs.
- Build accessibility in from the start.
- Make all interfaces responsive from mobile upward.
- Do not introduce dependencies without a concrete reason.

## Content

The website content is primarily Russian.

## Booking

There will be no booking form. Contact is through phone, Telegram, and WhatsApp.
